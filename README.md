## **AI Automation — Industry Immersion Course: Project Overview**

This repository captures the work completed so far for the AI Automation industry immersion Internship. It collects weekly checkpoints, experiment artifacts, prompt logs, and results so reviewers and future contributors can reproduce, learn from, and extend the work.

**Structure:**
- **Weeks:**: Weekly project folders with notes, reports, notebooks, and results.
- **Prompt Logs:**: Course prompt logs and notes collected during development.

**Weekly Summaries:**
- **Week 04 — Model Comparison:**: Model selection experiments and comparison results. **How to use this repo:**
- **Browse reports:**: Start with the weekly README and `report.md` files to understand objectives and results.
- **Inspect artifacts:**: Open CSVs, confusion matrices, and notebooks in the `results/` and `metrics/` folders to reproduce evaluations.
- **Re-run experiments:**: Follow each week's README for specific commands or notebook steps. Where notebooks exist, open them in Jupyter or VS Code.

**Results & Artifacts:**
- **CSV results and comparison tables:**: Stored under each week's `results/` folder.
- **Screenshots and figures:**: Many weeks include a `screenshots/` folder for visual context.

**Next steps / Suggested work:**
- **Consolidate notebooks:**: Add small runnable notebooks that reproduce a single experiment end-to-end.
- **Add environment spec:**: Provide a `requirements.txt` or `environment.yml` for reproducibility.
- **Automate evaluation:**: Add scripts to standardize metric computation across weeks.
